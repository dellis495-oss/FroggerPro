Project topics: `nothing-phone-custom-rom`, `e-os`

| Option | Build | Signing |
| --- | --- | --- |
| e/OS test build | e-4.4-a17-20261018-UNOFFICIAL-FroggerPro.zip | Android test keys |
| e/OS private release build | e-4.4-a17-20261018-private-release-UNOFFICIAL-FroggerPro.zip | October private release keys |

These are historical October builds. The November face enrollment fix is in
the newer source and was tested on a later image. The October release keys are
unavailable, so a future release uses a different signing identity.

Release assets are pending upload. If the ZIP is distributed in parts, download
all parts and SHA256SUMS for one option into the same directory. Reassemble the
parts in numeric order and verify the original ZIP checksum before use.

Use the recovery and installation instructions that correspond to the exact
build and signing identity you choose.
